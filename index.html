What it does

Timer reload

Any interval from 1 second to 24 hours, with one-click presets. Built for Manifest V3, so it keeps time even when Chrome suspends the extension.

Badge countdown

The toolbar badge shows the time until the next refresh, on every tab you're watching.

Right-click pause

Pause or resume from any page or from the toolbar icon. Resume picks up where it left off.

Per-site memory

Your interval is remembered for each website and filled in next time. (Unlock)

Scheduling

Only refresh during set hours, e.g. 09:00 to 17:00. Overnight windows work too. (Unlock)

Private by design

No analytics, no tracking, no ads, no remote code. The extension can't read your pages.
