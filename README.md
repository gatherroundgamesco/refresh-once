# Refresh Once - website

Static landing page and privacy policy for the Refresh Once Chrome extension, served by GitHub Pages at
https://gatherroundgamesco.github.io/refresh-once/ (privacy policy: https://gatherroundgamesco.github.io/refresh-once/privacy/).

Plain HTML/CSS with relative paths only: no build step, no tracking, no cookies, no external fonts or CDNs.
`.nojekyll` tells GitHub Pages to serve the files as-is.
